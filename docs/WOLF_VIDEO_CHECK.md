# 狼 · 与 B 站实机视频逐只核对

这一轮的目标：**把游戏里的狼和 B 站实机录像逐个比一遍**，看模型接得对不对。
和 `docs/ART_PIPELINE.md` 里「模型怎么来的」配套——那篇讲怎么从原站抠出模型，这篇讲
「抠出来之后，实机画面里是不是就长这样」。

底片：B 站 **BV1CusDeKEN8《童年QQ空间神作保卫羊村全地图通关合集》**
（45 分P / 148 分钟 / 3.3 万播放）。这是目前能找到的唯一一份**全地图**实机录像。

## 1. 这一轮做了什么

1. **抽帧**：45 个分P 每 P 抽 7 帧（`tools/bili_frame.py`），存 `tools/_video/ref_all`、
   `tools/_video/ref_open`，共 301 张。
2. **认地图**：每 P 右上角飘带上写着村名。把飘带裁下来拼成一张表
   （`tools/_video/_names_all.png`）逐 P 读，得到 **分P → 关卡** 的对应
   （见 §4 的表）。**分P 顺序是 UP 主自己的通关顺序，不是关卡号顺序**——
   比如 p06 是第 7 关凯奇镇、p13 是第 16 关莫诺雷村、p37 是第 46 关枫威瀑布。
3. **抠狼**：`tools/video_wolf_grab.py` 用**狼头顶那根绿血条**定位，再用 GrabCut 收紧成
   96px 的方块（血条宽度随狼大小缩放，顺手把尺寸也归一化了）。
   血条是很纯的绿（R≈28 G≈197 B≈26），树叶虽然也绿但红蓝分量高得多，按颜色一刀切就能滤掉。
   最终从 301 帧里抠出 **789 张**实拍狼。
4. **比对**：`tools/wolf_video_match.py` 拿每张抠图跟 `assets/wolf/*.png` 的模型比。
   候选集不是全库 113 只，而是**这一关的狼表**（`js/data.js` 每张图的 `w.prop/boss/rb/fb`）
   ——分P 一认出来，候选就只剩 3~23 只，准得多；另外再按颜色粗筛几只「榜外狼」一起参选，
   用来抓引狼 / 随机 BOSS 这种没写进狼表的情况。
   打分分两步：先按颜色直方图 + 剪影粗排，再对前几名做**带掩膜的零均值归一化互相关**。
   > 踩过的坑：`cv2.matchTemplate` 的 `TM_CCORR_NORMED` **不做去均值**，
   > 亮而"省事"的模板（雪狼那种大白狼）对深色狼也能刷出 0.93 的高分，完全没法区分。
   > 换成手写的 ZNCC（去均值 + 掩膜 + 小范围位移/尺度搜索）之后，正确匹配在 0.8~0.9、
   > 认错的掉到 0.4~0.6，才分得开。
5. **出图**：
   * `tools/wolf_video_cards.py` → `tools/_video/_report/parts_*.png`：**按分P**的核对卡片
     （左边是这一关的狼表 + 我们的模型，右边是这一 P 抠出来的实拍）。
   * `tools/wolf_video_report.py` → `tools/_video/_report/sheet_*.png`：**按狼种**的对照表
     （左：我们的 `d`/`r` 两帧；右：实拍抠图 + 分数 + 出处分P）。
   * `tools/wolf_video_make_page.py` → **`tools/wolf_video_check.html`**：把上面这些东西
     和下面的统计拼成一个可以直接翻的页面。

## 2. 结论

| 项 | 数字 | 说明 |
|---|---|---|
| 视频分P | 45 | 45 P 各一张图（2026-09-30 更正：p10 不是大厅，是第 10 关沃夫沼泽，上一轮认错了） |
| 视频覆盖的地图 | **45 / 46** | 只缺第 20 关 苏兰德城（无限进度图） |
| 视频里出现过的狼种 | **128 / 132** | 按各关狼表取并集 |
| 其中有原作模型的 | **126 / 128** | 模型来自原站 `gameUI/dynamic/<id>.swf` |
| 没有原作模型 | **2** | `wjxcl_B` 玩具小丑（第 41 关）、`xxgl_B` 吸血鬼狼（第 42 关） |
| 视频里没出现过的狼种 | 4 | `daomu5X` 特洛伊木狼、`daomu6X` 天空萝莉、`fsyjblt` 飞行员吉贝丽塔、`zbjkX` 珍宝杰克 |

一句话：**录像能覆盖到的 128 只狼里，只有 2 只（玩具小丑、吸血鬼狼）本作没有原作模型，
还在退回程序化绘制**；其余 126 只都是原站矢量原画，实拍与模型对得上。

### 还差什么

* **玩具小丑 / 吸血鬼狼**：这一轮没能在录像里逮到清楚的一帧（两只都在后期图，
  画面里怪多、遮挡重），所以**没有实拍可比**，暂时只能保留程序化绘制。
  想补的话：抓 p44（缠怨谷）/ p38（金沙桥）里 BOSS 出现的那几分钟，按帧扫一遍。
* **抠图质量**：789 张里能进自动比对的是 532 张，剩下的是 GrabCut 没分出前景
  （塔挡、狼挤在一起）。这部分现在只能靠人眼看 `parts_*.png`。
* **只比了外观**：这一轮没有逐只核**动作帧数 / 行走速度**。帧数可以用
  `tools/wolf_seq_check.html` 对着看，实拍这边要抽连续帧（现在每 P 只抽了 7 帧）。

### 这份核对**没有覆盖**的（2026-09-30 复盘补充）

* **狼的血条 / 状态特效 / BOSS 名牌**：上一轮的比对只比了「身体」。复盘时发现用了原作狼模型之后
  `Art.drawWolf` 画完精灵就直接返回，**血条、减速/中毒/燃烧/眩晕/护盾/沉默特效、BOSS 名牌、受击闪白全部丢了**。
  已修：`Art.drawWolfOverlay`（js/art_chars.js）由程序化狼和原作狼共用。
* **狼相对格子的大小**：原作格子是 65×50（见 ART_PIPELINE §9.4），狼的精灵图是按 96×96 归一化烘的，
  各狼之间的真实大小差靠 `js/data.js` 的 w/h 换算（`def.size`），还没有逐只拿实拍量过。
* **行走帧率 / 速度**：还没核。

## 3. 怎么复核

```bash
python tools/video_wolf_grab.py        # 抠图  -> tools/_video/_wcrops/
python tools/wolf_video_match.py       # 比对  -> match.json
python tools/wolf_video_cards.py       # 按分P 卡片
python tools/wolf_video_report.py      # 按狼种对照 + species.json
python tools/wolf_video_make_page.py   # -> tools/wolf_video_check.html
```

无头截图（本机 Chrome 要带 `--no-sandbox`，否则 GPU 进程起不来）：

```bash
chrome --headless=new --no-sandbox --disable-gpu --allow-file-access-from-files \
       --user-data-dir=<空目录> --virtual-time-budget=9000 --window-size=1500,2400 \
       --screenshot=out.png "file:///.../tools/wolf_video_check.html"
```
