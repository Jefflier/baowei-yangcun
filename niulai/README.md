# 牛来攻城 · 保卫羊村番外篇

羊村的城池被牛群围攻了！这是一款**纯前端、双击即玩**的迷宫式塔防，用《保卫羊村·怀旧服》单机复刻的底子手搓而成。

- 源码版：双击 `niulai/index.html`（或在仓库根目录运行 `python tools/devserver.py`，打开 <http://localhost:8123/niulai/>）
- 单文件版：`dist/牛来攻城.html`（约 2.9 MB，无外部依赖，发给朋友直接双击）；改了源码后 `python tools/build_niu.py` 重新生成
- 保卫羊村的标题页上有「🐂 番外 · 牛来攻城」按钮可以直接跳过来，本作标题页底部也能跳回去

## 核心玩法：路可以堵死，但牛会撞墙

牛群从左边的牛群入口冲向右边的**羊城城门**，每冲进去一头就扣城防（大牛扣得多），20 点城防归零即失败。
你要用城墙把路绕长、用塔在路上把牛打倒——这部分和保卫羊村一样。不一样的是**攻城**：

- 保卫羊村里「不能把路完全堵死」；这里**随便堵**，牛会自己**撞墙破城**。
- 寻路沿用羊村 `core.js` 的 Dijkstra 流场，但给建筑加了通行代价：
  `代价 = 3 + 剩余耐久 / 参考破坏力`（普通牛 7，撞城牛 30）。
  于是牛会自己算账——**绕远路**还是**撞开一堵墙**更快：木栅 ≈ 20 格、石墙 ≈ 67 格、铁壁 ≈ 174 格。
  墙越结实越愿意绕路；墙被撞薄了，代价下降，整群牛就会改道一拥而上。
- **撞城牛**用单独一张「攻城流场」，眼里的墙只有普通牛的 1/4 厚，会直奔最薄的那堵墙。
- 塔、雕像也是建筑，同样会被撞塌；火牛倒下会爆炸，牛魔王会震地——迷宫会被打烂，需要修理和升级。
- 地图上白色虚线是牛现在的路线，红色「撞」标出它们打算撞开的建筑；有撞城牛的关卡另画一条橙色的攻城路线，
  有飞天牛的关卡画一条蓝色的航线。造建筑时悬停就能**预览**放下去之后路线怎么变。
- 选中一堵墙，面板会告诉你「牛眼里撞开它 ≈ 多走 N 格路」。

## 12 种牛

| 牛 | 特点 |
|---|---|
| 小黄牛 | 最普通的黄牛 |
| 小牛犊 | 小、快、脆 |
| 奶牛 | 每 4 秒给身边的牛回 10% 生命——先打它 |
| 斗牛 | 周期性冲锋（×2.2 速度），冲锋中撞墙伤害 ×3 |
| 水牛 | 火焰伤害减半，雷电伤害 +50%（浑身湿的） |
| 牦牛 | 冰冻伤害减半，几乎不吃减速 |
| 撞城牛 | 头顶攻城锤，撞墙伤害极高，专挑最薄的墙撞 |
| 飞天牛 | 挂着原作的气球直线飞向城门，无视城墙和河；炮塔打不到，散弹塔对空 ×2 |
| 铁甲牛 | 物理伤害每下减 8；铁甲导电，怕雷 |
| 火牛 | 田单火牛阵：免疫火焰、怕冰，倒下时爆炸炸坏身边的建筑 |
| 青牛精（BOSS） | 兕大王，每 6 秒甩出金刚琢收走附近一座塔的法力（停火 4 秒） |
| 牛魔王（BOSS） | 震地眩晕附近的塔、召唤牛群、半血狂暴 |

牛是**纯手搓的 Q 版矢量**（侧身 + 正脸大头、8 帧走路、冲锋/狂暴/受击变体），见 `js/niu_art.js`；
按帧烘进离屏画布缓存，受击白闪用 `source-atop` 做在缓存里。牛倒下会「哞~」一声（Web Audio 现合成）。

## 8 种塔 + 建筑 + 城主技能

塔直接用保卫羊村导出的**原作矢量**：五级外观正好对应原作的石 / 蓝 / 黄 / 红 / 金五档；元素塔是原作镶嵌塔换宝石色。

| 塔 | 作用 |
|---|---|
| 哨塔 | 便宜可靠的单体输出 |
| 散弹塔 | 同时打 3 个目标，对空 ×2 |
| 炮塔 | 射程最远的范围伤害，只打地面 |
| 冰晶塔（蓝宝石） | 范围减速 |
| 烈焰塔（红宝石） | 点燃，3 秒持续灼烧 |
| 雷霆塔（紫宝石） | 连锁闪电弹射 |
| 波动塔 | 贯穿一条直线最多 10 头，无视护甲 |
| 毒蒺藜塔（绿宝石） | 按最大生命百分比掉血，克 BOSS |

- **城墙**：木栅（手搓）→ 石墙（原作 `qiang`）→ 铁壁（原作石墙 + 铁箍），耐久 120 / 450 / 1200，可按住拖动连续造。
- **草垛**：放在路上（可以放在桥和大路上），路过的牛停下吃草 1.5 秒，能吃 6 口。
- **盘龙柱**（攻速 +25%）、**织女像**（射程 +20%）：原作雕像。**牛郎像**：牧歌安抚附近的牛，移速 -30%、撞墙伤害 -60%。
- **城主技能**：滚木礌石（选一行推下滚木，伤害 + 眩晕）、冰封千里（全场冻住）、八方修缮（建筑回 50% 耐久、城防 +1）。
- 塔可以升级、修理、出售（开战前 / 刚造 3 秒内全额退）、切换目标优先级（最前 / 最强 / 最弱 / 最近），点一头牛让塔**集火**。

## 10 关 + 无尽

牛家村 → 青草坡 → 小河湾（只能从两座桥过河）→ 石头岭（撞城牛登场）→ 风车田（飞天牛）→ 牦牛雪原（青牛精）
→ 铁甲关（峡谷缺口）→ 火牛阵 → 两界山（三路进攻）→ 火焰山（牛魔王）。通关第 5 关解锁**无尽牧场**（每 10 波青牛精、每 25 波牛魔王）。
每关按剩余城防给 1~3 星；新塔、新建筑、新技能随关卡逐步解锁；第一次见到的牛会弹出介绍卡，图鉴里能查。

## 操作

| 按键 | 作用 |
|---|---|
| `1`~`8` | 八种塔 |
| `Q` / `W` | 城墙（按住拖动）/ 草垛 |

| `空格` / `F` / `N` / `P` | 暂停 / 1×2×3× 加速 / 提前叫下一波（按剩余时间给奖励）/ 显示路线 |
| 右键、`Esc` | 取消；按住 `Shift` 连续造塔 |

## 复用了保卫羊村的哪些东西

- `js/core.js`：工具函数与存档（`SV.store`、`SV.fmt`…）；寻路思路来自它的 Dijkstra 流场（本作扩成加权版，自带二叉堆）
- `js/audio.js` + `assets/audio/sounds.js`：原作 35 个 mp3 的音效与战斗音乐（BOSS 波切 BOSS 曲），缺了自动退回程序化音效
- `js/art_original.js` + `assets/art/*.js`：原作矢量——五种塔 × 五档、石墙、盘龙柱 / 牛郎 / 织女、树和石头、羊的表情（城头的羊平时开心、城门挨打时害怕、城防低了会哭）、飞天牛的气球

```
niulai/index.html        入口（引用上级目录的 core.js / audio.js / 原作素材）
niulai/css/niu.css       样式
niulai/js/niu_data.js    数据：牛 / 塔 / 建筑 / 技能 / 10 关地图与波次参数
niulai/js/niu_engine.js  引擎：加权流场、撞墙、波次、塔与弹道、技能（不碰 DOM，node 里能跑）
niulai/js/niu_art.js     美术：手搓的牛、原作矢量的缓存与兜底画法、图标
niulai/js/niu_render.js  战斗渲染：地形、城池、路线预览、弹道与特效；标题画面
niulai/js/niu_ui.js      界面：标题 / 选关 / HUD / 建造栏 / 选中面板 / 弹窗 / 输入 / 主循环 / 存档
niulai/js/niu_main.js    启动
tools/niu_sim.js         无头平衡模拟：一个会摆蛇形迷宫、用草垛雕像技能的 AI 把每关各跑几遍
tools/niu_trace.js       单关逐波追踪（AI 布阵图 + 每波漏牛 / 击杀 / 被撞塌的建筑）
tools/build_niu.py       打包单文件版 dist/牛来攻城.html（原作矢量包只留用到的符号）
```

## 平衡

用 `node tools/niu_sim.js --runs 3` 跑：AI 玩家（蛇形迷宫 + 按覆盖摆塔 + 草垛 / 雕像 / 技能，但不会集火、不会看情况修关键墙）
稳定通过 1~9 关，最终关火焰山大约三局赢一局——留给人类玩家的操作空间。数值都集中在 `niu_data.js`，
改完跑一遍模拟就知道难度曲线有没有歪。
